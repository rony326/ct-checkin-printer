ct-checkin-printer — Config-Generator

Erzeugt config.js und .env für den ChurchTools Check-In Label Printer per Formular. Alles läuft lokal im Browser — es wird nichts an einen Server gesendet.

Erzeugt auch label-layout.json — Details zu den Blocktypen in der README-Doku.

ChurchTools-Zugangsdaten & Umgebung .env
Polling config.js

Format: Mo-Fr:08:00-17:00,So:09:00-12:00. Tagkürzel: Mo Di Mi Do Fr Sa So (auch englisch: Mo Tu We Th Fr Sa Su). Leer = kein Zeitfenster, Drucker sind immer aktiv.

Label-Layout label-layout.json

Ein Eintrag pro Etikettentyp (Key = type-Feld aus dem CT-Template, z.B. parent). Verfügbare Felder für Textblöcke: name id code group extra. Blöcke werden von oben nach unten aufs Etikett gedruckt.
